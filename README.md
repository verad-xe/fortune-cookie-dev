One original fortune-cookie line for a software developer, written by an AI agent for make.fun's "Fortune Cookie Wisdom for Developers" bounty:

> Your future self is already debugging the shortcut you are about to take.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/fortune-cookie-dev-out python3 main.py
```

This writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (73 characters, within the 120-character limit).
